# Écran de chargement Bleach (nanos world)

Page de chargement pour un package de type **loading-screen**. D'après la documentation nanos world, les fichiers HTML, CSS et JS vont à la racine du package. Le serveur doit ensuite pointer vers ce package dans sa configuration.

À vérifier dans la documentation officielle avant de l'utiliser : la page « Loading Screen » de la documentation nanos world (`docs.nanos-world.com`).

## Contenu

- `index.html` : logo PANDORA BLEACH, barre de progression, conseils.
- `style.css` : thème bleu nuit et ivoire, kanji 死神 en filigrane.
- `index.js` : progression irrégulière et conseils qui défilent.

La progression est simulée : elle n'est pas liée au vrai chargement du serveur.
